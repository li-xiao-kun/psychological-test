## 👥 权限体系与后台数据管理

本项目现已全面支持**普通受测者权限**与**管理员管理权限**隔离体系：

### 1. 普通受测者权限（访客/学生/孩子）
- **私密填写**：可选填受测者昵称/代号与班级，保护隐私；
- **答题自测**：完成 10 道身心电量评测与悄悄话小树洞；
- **专属结果**：只能查看属于自己的能量体检单、下载海报、复制总结；
- **严格隐私保护**：普通权限**无法**查看其他任何人的答题记录、统计大屏或他人的树洞小秘密。

### 2. 管理员管理权限（老师/心理咨询师/家长）
- **安全登录入口**：页面右上角「🔐 管理员后台」按钮，输入口令即可进入管理中心；
- **初始默认密码**：`admin123`（进入管理中心后可点击「🔑 修改管理密码」随时修改）；
- **全量后台数据工作台**：
  1. 📊 **统计大屏看板**：实时汇总累计测评人次、平均身心负荷分、🚨重点关爱预警人数、树洞倾诉留言数；
  2. 🔍 **多维智能检索**：支持按姓名、代号、班级关键词实时搜索；
  3. 🚨 **风险快速过滤**：可一键筛选出“重点关爱预警（总分>14分或有强烈孤独感）”的名单，便于老师或心理辅导人员及时跟进干预；
  4. 📋 **逐题答卷明细**：点击「详情」即可调出该受测者的完整答卷，查看 10 道题的逐题选择及悄悄话全文；
  5. 📥 **一键导出 Excel / CSV**：点击「导出 Excel / CSV 表格」，即可一键下载标准 UTF-8 BOM 编码的表格文件，在 Excel / WPS 中双击即可打开，中文绝不乱码，方便归档和打印！

## 💾 数据存储双模式说明

### 模式一：纯静态 GitHub Pages 部署模式（零配置开箱即用 · 推荐）
- 直接通过 GitHub Pages 免费托管部署，无需购买任何服务器或数据库；
- 普通用户提交后，数据会自动加密保存在本地后台数据池中；
- 管理员点击右上角「管理员后台」输入密码登录后，即可在同一设备或浏览器中查阅所有答卷、检索和一键导出 Excel 表格！

### 模式二：独立 Python 后端服务模式（支持多设备/局域网数据集中上报）
若希望在学校微机室、家庭或自有服务器上让多台手机/电脑将数据实时汇聚到同一个中心数据库：
1. 确保电脑已安装 Python 3（无需 `pip install` 任何第三方包，纯标准库支持）；
2. 在项目目录运行：
   ```bash
   python server.py
   ```
3. 服务将在 `http://localhost:8080` 启动，并自动在本地生成 `psychological_data.db` (SQLite 数据库)；
4. 页面会自动检测并打通与后端的连接，绿灯常亮，所有提交将实时持久化到 SQLite 数据库中！

## 💡 计分规则与电量说明

问卷共 10 道题目，每题单选：
* **0分**：完全没有（或者极少这样）
* **1分**：偶尔有几天这样
* **2分**：有一半以上的时间都这样
* **3分**：几乎每天都这样

### 能量分级：
| 得分区间 | 心理状态标签 | 状态说明 |
| :--- | :--- | :--- |
| **0 ~ 4 分** | ☀️ 阳光充沛的小树苗 | 心理电量充足，充满活力与韧性 |
| **5 ~ 9 分** | ⛅ 偶遇微风云朵的小草 | 轻微耗电，遇到学业或生活小波折，需适当放松 |
| **10 ~ 14 分** | 🔋 呼叫关怀的蓄电池 | 中度疲惫，压力较沉重，需要陪伴与倾听 |
| **15 ~ 30 分** | 🫂 特别需要被爱的小天使 | 高负荷预警，建议主动向信任的家长、老师或心理医生求助 |

## 🚀 GitHub Pages 前端部署上线步骤

代码已全部编写完毕，已推送或可通过以下命令提交至 GitHub：

```bash
# 1. 提交新更新
git add .
git commit -m "feat: 增加后台数据存储、双权限体系与Excel导出功能"

# 2. 推送到远程 main 分支
git push origin main
```

### 开启 GitHub Pages（若尚未开启）：
1. 打开 GitHub 仓库：[https://github.com/li-xiao-kun/psychological-test](https://github.com/li-xiao-kun/psychological-test)；

3. 将 **Branch** 设置为 **`main`**，文件夹选 **`/ (root)`**，点击 **`Save`**；
4. 等待 1~2 分钟刷新，即可通过 [https://li-xiao-kun.github.io/psychological-test/](https://li-xiao-kun.github.io/psychological-test/) 线上访问！
