## ✨ 项目特色

1. **温和治愈的视觉与交互设计**：
   - 自然森林绿与暖阳色调，治愈系微动效与拟物电池呼吸动画。
   - 移动端单手操作优化，大圆角舒适卡片，选项自适应高亮与智能平滑跳转。
2. **科学温和的 10 项身心电量评测**：
   - 包含开心与爱好、情绪天气、脾气烦躁、身体疲惫感、睡眠质量、食欲胃口、大脑运转、躯体化不适、自我认知、孤独感与求助等 10 个关键维度。
3. **分层关爱与电量评估报告**：
   - 实时生成个性化“心情与能量体检单”及专属心理可用电量刻度。
   - 自动生成针对性的“能量充能小处方”（作息、运动、倾诉、宣泄小妙招）。
   - **特殊心理危机守护安全网**：针对孤独感与严重无助状态，自动触发红色温情防护提醒，并提供 12355、希望24小时等国家公益援助热线。
4. **贴心实用功能**：
   - 💬 **悄悄话小树洞**：支持倾诉选填，记录心事。
   - 📸 **一键生成海报**：使用 HTML5 渲染导出精美打卡长图。
   - 📋 **一键复制总结**：方便将测评结果发送给家长、心理辅导老师。
   - 📖 **本地打卡日记**：采用浏览器 `localStorage` 本地隐私存储，安全无忧，无任何第三方数据收集。
5. **极简零依赖部署**：
   - 纯原生 HTML5 + CSS3 + Vanilla JavaScript，无需 Node.js/npm 打包编译，直接推送到 GitHub 即可秒级通过 GitHub Pages 免费上线。

## 💡 计分规则与电量说明

问卷共 10 道题目，每题单选：
* **0分**：完全没有（或者极少这样）
* **1分**：偶尔有几天这样
* **2分**：有一半以上的时间都这样
* **3分**：几乎每天都这样

### 能量分级：
| 得分区间 | 心理状态标签 | 状态说明 |
| :--- | :--- | :--- |
| **0 ~ 4 分** | ☀️ 阳光充沛的小树苗 | 心理电量充足，充满活力与韧性 |
| **5 ~ 9 分** | ⛅ 偶遇微风云朵的小草 | 轻微耗电，遇到学业或生活小波折，需适当放松 |
| **10 ~ 14 分** | 🔋 呼叫关怀的蓄电池 | 中度疲惫，压力较沉重，需要陪伴与倾听 |
| **15 ~ 30 分** | 🫂 特别需要被爱的小天使 | 高负荷预警，建议主动向信任的家长、老师或心理医生求助 |

## 🚀 GitHub Pages 前端部署上线步骤

本项目已经完成了本地代码构建，按照以下简单两步即可永久免费部署上线：

### 第一步：将代码推送到 GitHub 仓库

在终端（Terminal 或 PowerShell）中执行：

```bash
# 1. 进入项目根目录
cd "e:\我的项目\心里测试小程序"

# 2. 初始化 Git 仓库并提交代码
git init
git add .
git commit -m "feat: 初次提交心情与能量小打卡网页"

# 3. 关联远程 GitHub 仓库
git branch -M main
git remote add origin https://github.com/li-xiao-kun/psychological-test.git

# 4. 推送到远程 main 分支
git push -u origin main
```

### 第二步：开启 GitHub Pages 自动化部署

1. 打开你的 GitHub 仓库主页：  
   `https://github.com/li-xiao-kun/psychological-test`
2. 点击仓库顶部的 **`Settings`**（设置）选项卡。
3. 在左侧菜单栏中找到 **`Pages`**。
4. 在 **`Build and deployment`** 下：
   - **Source** 选择：`Deploy from a branch`
   - **Branch** 选择：`main` 分支，文件夹保持 `/ (root)`。
   - 点击 **`Save`** 保存。
5. 等待 1~2 分钟刷新页面，GitHub Pages 会在页面顶部提示部署成功的绿色网址：  
   `https://li-xiao-kun.github.io/psychological-test/`
6. 直接把这个链接发给学生、家长或朋友，在微信、手机浏览器、电脑浏览器均可顺畅访问！
