## 📡 核心：别人在手机上答完题，管理员如何实时看到？

由于 GitHub Pages 是静态网站托管，默认情况下每位受测者在自己的手机浏览器里答完题，数据会保存在受测者自己的手机本地。

为了实现 **“任何人在任何地方用手机答完题，管理员都能实时看到全量数据”**，系统内置了以下三种跨设备同步通道：

### 📱 方案一：微信实时秒推（🌟 强烈推荐 · 系统已内置配置）
系统已内置你的专属微信推送通道！只要别人在任何手机或电脑上点击“完成打卡”，**你的个人微信会立即收到一条图文卡片通知**，即使你没打开电脑，手机也会立刻响铃提醒！
- **通知内容包含**：受测者姓名/代号、班级、总得分数、心理电量级别、是否触发高危预警、10道题目单题得分清单、树洞悄悄话全文。
- **开箱即用**：你无需重复配置，任何人打卡均会自动推送到你的微信；如需在管理后台测试或变更，可随时在后台「⚙️ 跨设备同步/微信提醒」中查看与测试。

---

### ☁️ 方案二：LeanCloud 免费云端数据库（在后台网页表格实时查看所有人）
若你希望在管理后台网页中，像看花名册一样查看全网所有受测者的汇总表格、实时搜索、一键导出 Excel：
1. 访问 [LeanCloud 官网](https://www.leancloud.cn) 注册一个免费开发者账号（提供永久免费额度）；
2. 创建一个应用，在「设置」->「应用凭证」中复制你的 `AppID` 和 `AppKey`；
3. 打开你的网页管理后台，点击 **「⚙️ 跨设备同步/微信提醒」**，填入你的 AppID 和 AppKey 保存；
4. 之后全国各地所有手机提交的数据，都将自动实时存入云端数据库，你在任何电脑/手机打开后台点击“🔄 刷新”，所有人答卷立刻整齐列出！

---

### 🖥️ 方案三：自建 Python 服务器（支持局域网或云主机）
如果你在学校微机室、家庭或自有云服务器上运行：
1. 在项目目录直接运行：
   ```bash
   python server.py
   ```
2. 服务将在本地 `http://localhost:8080` 启动，自动生成 `psychological_data.db`（SQLite 数据库）；
3. 打开后台设置，填入该服务地址，系统即可自动通过私有 SQLite 存储数据。

## 💡 计分规则与电量说明

问卷共 10 道题目，每题单选：
* **0分**：完全没有（或者极少这样）
* **1分**：偶尔有几天这样
* **2分**：有一半以上的时间都这样
* **3分**：几乎每天都这样

### 能量分级：
| 得分区间 | 心理状态标签 | 状态说明 |
| :--- | :--- | :--- |
| **0 ~ 4 分** | ☀️ 阳光充沛的小树苗 | 心理电量充足，充满活力与韧性 |
| **5 ~ 9 分** | ⛅ 偶遇微风云朵的小草 | 轻微耗电，遇到学业或生活小波折，需适当放松 |
| **10 ~ 14 分** | 🔋 呼叫关怀的蓄电池 | 中度疲惫，压力较沉重，需要陪伴与倾听 |
| **15 ~ 30 分** | 🫂 特别需要被爱的小天使 | 高负荷预警，建议主动向信任的家长、老师或心理医生求助 |

## 🚀 GitHub Pages 前端部署上线步骤

代码已全部推送到 GitHub 远程仓库，按照以下步骤开启 Pages 服务即可：

1. 打开 GitHub 仓库：[https://github.com/li-xiao-kun/psychological-test](https://github.com/li-xiao-kun/psychological-test)；
2. 进入 **`Settings` -> `Pages`**；
3. 将 **Branch** 设置为 **`main`**，文件夹选 **`/ (root)`**，点击 **`Save`**；
4. 等待 1~2 分钟刷新，即可通过 [https://li-xiao-kun.github.io/psychological-test/](https://li-xiao-kun.github.io/psychological-test/) 线上访问！
